
# AutoLoc - Car Rental Management System

## About the Project

AutoLoc is a car rental management application developed using Java and Spring Boot.

The main objective of this project is to simplify car rental operations by managing vehicles, clients, employees, agencies, reservations, contracts, payments, equipment and maintenance.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- IntelliJ IDEA

## Main Features

- Vehicle management
- Client management
- Employee management
- Agency management
- Reservation management
- Contract management
- Payment management
- Equipment management
- Vehicle maintenance management

## Project Structure

The project follows a structured Spring Boot architecture with domain entities and enums.

## Database

MySQL is used to store and manage application data.

## Installation

1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Configure your MySQL database connection.
4. Run the Spring Boot application.
